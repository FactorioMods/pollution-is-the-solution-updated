# Pollution is the Solution: Updated

Make pollution-fed enemy nests expire after spawning 60 units, while retaining the original nearby-enemy safeguard for biter farms. Nuclear ground also blocks new nests.

This fork updates the original mod for Factorio 2.1.24 and retains its existing prototype and setting names. Replace the original with this fork; both cannot be enabled together. Existing-save loading and two 1,200-tick headless consistency runs completed with this fork enabled.

Original mod by Mylon: [Mod Portal](https://mods.factorio.com/mod/Pollution_is_the_Solution). Fork source: [GitHub](https://github.com/FactorioMods/pollution-is-the-solution-updated). Original credits and bundled license remain applicable.
